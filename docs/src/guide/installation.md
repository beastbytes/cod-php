# Installation

Install **CodPhp** using [Composer](https://getcomposer.org/).

Either using the command-line:
```shell
composer require --dev beastbytes/cod-php
```

or add
```json
"beastbytes/cod-php": "{{vesrion constraint}}"
```

to the `require-dev` section of the project `composer.json`.

## Requirements

**CodPhp** requires:

* PHP 8.4 or higher.
* Installation and namespace definition using [Composer](https://getcomposer.org/).
